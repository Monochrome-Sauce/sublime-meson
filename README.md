# Meson Build - unofficial Sublime Text syntax package

[Meson](https://mesonbuild.com) build system integration for Sublime Text.

This package adds syntax highlighting for `meson.build` and `meson-options.txt`
files, and should work as is.

## Installation

### Package Control

Install it from [Package Control](https://packages.sublimetext.com/packages/Meson).

### Manual Installation

Copy this repo's folder into your Sublime Text `Packages` directory. You will need to rename the folder to "Meson".

## Contributing

Check out the [issues](https://github.com/Monochrome-Sauce/sublime-meson/issues).

And generally speaking, this repository only accepts contributions related to
Meson syntax. Python code is no longer accepted.
